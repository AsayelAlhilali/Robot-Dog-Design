# Object Recognition using OpenCV and YOLOv8 model

## Overview
This project performs real-time object recognition using a laptop camera with OpenCV and the YOLOv8 pre-trained model.

## Tools
- Python
- Jupyter Notebook (Anaconda)
- OpenCV
- Ultralytics YOLOv8
- Visual Studio Code (VS Code)

## Features
- Real-time object detection
- Displays object labels
- Displays confidence scores
- Draws bounding boxes

## Testing
The model was tested using random everyday objects, including:
- 💧 Water Bottle
- 📱 Cell Phone
- ✂️ Scissors
- ☕ Cup
-  Remote 

detected objects were displayed with bounding boxes, labels, and confidence scores in real time.
