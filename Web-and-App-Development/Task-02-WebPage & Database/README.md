# Smart Methods PHP Task

## Overview

This project is a simple PHP & MySQL web application that allows users to:

- Add new users (Name and Age)
- Store records in a MySQL database
- Display all records in a table
- Toggle the user's status between Active and Inactive

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- InfinityFree

## Features

- User-friendly interface
- MySQL database integration
- Status toggle functionality

## Database

Table:

```
users
```

Columns:
- id
- name
- age
- status
